# Adopters

This file lists organizations and teams using Apiloom Gateway CE in production, staging, or evaluation environments. Inclusion here is voluntary and self-attested.

If you are running Apiloom Gateway CE and would like to be listed, open a pull request adding a row to the table below, or email `hello@apiloom.io` and we will open the PR for you.

## Format

| Organization | Environment | Use Case | Contact / Link |
|---|---|---|---|
| Org name | Production / Staging / Evaluation | One-line description of what you use it for | Public link, GitHub handle, or "private" |

## What "adopter" means here

You qualify as an adopter if any of the following is true:

- You run Apiloom Gateway CE in a production environment.
- You run it in a staging or pre-production environment with the intent to ship to production.
- You operate a meaningful internal evaluation (multiple weeks, multiple services, real traffic).

Hobby projects, learning installations, and one-off experiments are welcome in the community but should not be listed here. The point of this file is to give prospective users a real signal about who is running the project for real.

## Privacy

If your organization cannot be named publicly, you can still help by sending a brief private statement to `hello@apiloom.io`. We will keep it confidential and use it (anonymized) in CNCF Sandbox / Incubating materials and in aggregate counts only.

## CNCF context

This file exists in part to satisfy the [CNCF Sandbox](https://github.com/cncf/sandbox) and [CNCF Incubating](https://github.com/cncf/toc/blob/main/process/graduation_criteria.md#incubating-stage) maturity criteria. Sandbox accepts a placeholder or single early-adopter entry. Incubating expects a credible set of independent end-user statements. Help us get there by sharing your story.
