# Maintainers

This file lists the current maintainers of the Apiloom Gateway CE project.

Maintainers are responsible for reviewing and merging pull requests, triaging issues,
cutting releases, and setting the technical direction of the project. See
[GOVERNANCE.md](GOVERNANCE.md) for the full maintainer ladder and decision-making process.

## Becoming a Maintainer

See the [Governance document](GOVERNANCE.md) for the process. In short: demonstrate
sustained, high-quality contributions across multiple areas of the codebase, then
get nominated by an existing maintainer. Unanimous maintainer approval required.
